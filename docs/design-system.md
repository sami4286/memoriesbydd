# Memories by DD — production design system

This document governs the active Vite/Netlify site in `_deploy/`. Historical Webflow concepts and early design notes do not override it.

## Art direction

- Quiet, cinematic mourning aesthetic: warm black, ivory, antique gold and restrained brown.
- Product artwork is shown whole with `object-fit: contain`; only portraits may use deliberate cropping.
- Spatial depth supports the content. It must never make scrolling twitchy, move text out of alignment or obscure an interaction.
- Section boundaries dissolve into one continuous dark canvas. Hairlines organise content without making sections resemble disconnected boxes.

## Typography

| Role | Scale | Rule |
|---|---|---|
| Microcopy | 16px | Labels, indices and metadata only |
| Body | 18px | Default reading size, 1.6–1.7 line-height |
| Card heading | `clamp(1.7rem, 2.7vw, 2.7rem)` | Short supporting titles |
| Section heading | `clamp(3rem, 5.25vw, 5.75rem)` | `clamp(2.55rem, 10.8vw, 3.4rem)` on mobile |
| Page hero | `clamp(4rem, 7vw, 7.4rem)` | `clamp(3rem, 12.7vw, 3.55rem)` on mobile |

Use Newsreader for editorial headings and Hanken Grotesk for interface and body copy. Keep one `h1` per page and preserve `h1 → h2 → h3` order. Paragraph measures should normally remain below 68 characters.

## Spacing

- Section padding: `clamp(5.25rem, 7.5vw, 8.5rem)` desktop; `4.25rem` mobile.
- Heading-to-content gap: 32–68px depending on viewport.
- Grid gaps: 12–20px for visual collections; 24–48px for editorial layouts.
- Mobile page gutters: 14px each side. Never position readable text outside the shared `.wrap`.
- Cards must not rely on `:last-child` for layout because spatial layers append decorative elements at runtime.

## Components

- Header and footer are generated by `scripts/standardize-shells.mjs` and stay identical across every page.
- Section 04 uses a 70/30 artwork-to-caption split, alternating sides on desktop. On mobile, artwork always precedes its caption.
- Catalogue cards use complete uncropped artwork, two columns on phones and wrapping titles.
- Phone and WhatsApp actions are accessible icons with explicit `aria-label` values.
- Interactive elements require a visible `:focus-visible` treatment and at least a 44px touch target.

## Motion

- Use `cubic-bezier(.16,1,.3,1)` for primary movement.
- Scroll-linked movement must be transform-only and scheduled with `requestAnimationFrame`.
- Do not hijack vertical scrolling for horizontal slideshows.
- Honour `prefers-reduced-motion` and disable depth effects on coarse pointers.

## QA contract

Before release run `pnpm qa` and `pnpm audit --audit-level=moderate`, then inspect at 390px, 768px, 1440px and 3840px widths. Required checks: no horizontal document overflow, no broken images, no text below 16px, consistent shared shell, visible focus states, complete product artwork and no console errors.
